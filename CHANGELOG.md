# EzMark

## v1.0.0

- First release for WoW Forever.
- Hold Alt and click a player's name in chat to put a raid marker over them (a red X by default). Alt+click them again to take it off.
- Works in a crowded city: if friendly nameplates are off, EzMark turns them on for a moment to find the player, then puts your setting back.
- `/mark <name>` marks a player by name; `/mark icon <1-8 or name>` changes the icon.
